R1. Under `{scripts}`, create the C# script `{cls}.cs` defining `public class {cls} : MonoBehaviour` with a serialized field `panel` of type GameObject (public, or marked [SerializeField]) and two public parameterless methods `TogglePause()` and `Resume()`. The project must compile without errors.
R2. Behaviour: the game is either running (`Time.timeScale` 1 and `panel` inactive) or paused (`Time.timeScale` 0 and `panel` active). `TogglePause()` pauses the game when it is running and resumes it when it is paused, whichever call brought it into its current state; `Resume()` always leaves the game running. When Play Mode starts the game is running (timeScale 1, `panel` still inactive) until a button is clicked.
R3. Attach the component to `{host}` (the only such component in the scene; another object in the scene has the same name, do not attach it there) and point its `panel` field, in the scene, at `{panel}`.
R4. Create two buttons with the UI skills: `{pauseBtn}` directly under `{canvas}` and `{resumeBtn}` directly under `{panel}`; both carry a Button component.
R5. Add a persistent listener (serialized into the scene and visible in the Inspector, not a runtime AddListener) to the onClick event of the Button component of `{pauseBtn}` that calls `TogglePause` of the component on `{host}`; add a persistent listener to the onClick of `{resumeBtn}` that calls `Resume` of the same component. Each onClick has only this one listener, with call state RuntimeOnly or EditorAndRuntime.
R6. `{panel}` stays inactive in the scene; do not modify the other object with the same name, `{canvas}` or any other existing object, and apart from this script do not add or change any code file (editor scripts included).
R7. Verification enters Play Mode and reads the initial state, then triggers the onClick of `{pauseBtn}` three times, then the onClick of `{resumeBtn}`, then `{pauseBtn}` once more and `{resumeBtn}` once more; after each of these six clicks it reads `Time.timeScale` and the active state of `{panel}`, which must follow R2 (a click on a button that is inactive at that moment does nothing). No error or exception may be logged while running.
R8. In the answer, report the script's asset path, the full hierarchy path of the object carrying the component, and the full hierarchy paths of the two buttons.

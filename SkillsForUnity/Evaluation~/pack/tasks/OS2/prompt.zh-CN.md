R1. 在已有的空 Screen Space Overlay Canvas `{canvas}`（CanvasScaler 参考分辨率 `{canvas_units}`）上搭建菜单。在其下直接创建一个激活的面板 `{panel}`，带 RectTransform 和启用的 UnityEngine.UI.Image。在面板下直接创建恰好 3 个激活的按钮，名称为 `{first}`、`{second}`、`{third}`，各带 RectTransform、启用的 UnityEngine.UI.Image 和 UnityEngine.UI.Button。每个按钮恰好有一个直接子标签，详见 R6。
R2. 面板的 anchorMin = anchorMax = pivot = (0.5, 0.5)，anchoredPosition = (0, 0)，sizeDelta = ({width}, {height})，单位为参考分辨率下的 UI 单位；本地 Z = 0，本地旋转 = (0, 0, 0)，本地缩放 = (1, 1, 1)。保持固定尺寸：ContentSizeFitter 必须不存在、被禁用，或两个 fit 均为 Unconstrained (0)。检查序列化的 RectTransform 值，不要求 Game 视图尺寸、世界坐标或计算后的像素矩形。所有指定的 UI/变换数值每个标量的绝对容差为 0.001，本地旋转用四元数夹角比较，容差为 0.001 度；枚举、布尔、数量和文字必须完全一致。
R3. 在面板上放置恰好一个启用的 UnityEngine.UI.VerticalLayoutGroup，spacing 为 {spacing}，padding 按 (left, right, top, bottom) 为 ({padding})；childAlignment 为 UpperCenter (1)，childControlWidth = childControlHeight = true，childForceExpandWidth = childForceExpandHeight = false，childScaleWidth = childScaleHeight = false。面板上不得有 HorizontalLayoutGroup 或 GridLayoutGroup。
R4. 每个按钮有一个启用的 UnityEngine.UI.LayoutElement，minWidth = preferredWidth = {button_width}，minHeight = preferredHeight = {button_height}，flexibleWidth = flexibleHeight = 0，ignoreLayout = false，layoutPriority = 1。按钮尺寸通过这些 LayoutElement 值检查，不检查可能被布局系统改写的 sizeDelta、锚点、pivot 或 anchoredPosition X/Y。每个按钮本地 Z = 0，本地旋转 = (0, 0, 0)，本地缩放 = (1, 1, 1)。
R5. 面板的直接子物体按兄弟顺序恰好为 `{first}`、`{second}`、`{third}`。全部 3 个 Button 组件均启用；`{first}` 和 `{second}` 的 interactable 为 true，`{third}` 为 false。
R6. 对应的标签文字在两种语言提示中均为 `{text_first}`、`{text_second}`、`{text_third}`，必须完全一致。每个标签激活，带 RectTransform、CanvasRenderer 和恰好一个启用的文字组件：UnityEngine.UI.Text（序列化 m_Text）或 TMPro.TextMeshProUGUI（序列化 m_text），两者均接受。标签 anchorMin = (0, 0)，anchorMax = (1, 1)，pivot = (0.5, 0.5)，anchoredPosition = sizeDelta = (0, 0)，本地 Z = 0，本地旋转 = (0, 0, 0)，本地缩放 = (1, 1, 1)；标签名称、字体、字号和颜色自由。
R7. 不得替换或修改任何已有物体的名称、层级、兄弟顺序、激活状态、tag、layer、本地变换、组件及序列化组件值，包括 Canvas 和 CanvasScaler。只能将新面板追加到已有 Canvas 下。Canvas RectTransform 受 Game 视图驱动的位置、缩放、锚点和尺寸除外。不得添加其他 Canvas、R 中任何其他物体或 A 中任何资产/文件夹/文件；已有文件和元数据（含标签及导入设置）必须不变。允许保存本轮场景。新增物体只能是面板、3 个按钮和它们的 3 个标签。新增菜单组件只能是 RectTransform、CanvasRenderer、UnityEngine.UI.Image、UnityEngine.UI.Button、UnityEngine.UI.VerticalLayoutGroup、UnityEngine.UI.LayoutElement、UnityEngine.UI.ContentSizeFitter 和两种可接受的文字类型。
R8. 报告实际 panelPath（不存在则为空字符串）、buttonPaths（本轮菜单按钮的实际完整路径，按 R 中深度优先、兄弟顺序排列）以及布尔值 declaredComplete。未完成时也应报告实际状态。

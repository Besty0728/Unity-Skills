### particle_get_module
| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `entityId` | string | No* | null | Target (or `name` / `path` / `instanceId`) |
| `module` | string | Yes | - | A module id from `particle_get_capabilities` (`main`, `shape`, `noise`, `system`, `renderer`, ...) |

# Unity Gameplay Blueprints

Documentation only: no REST skills. Use when starting a mini-game or vertical slice and a lightweight architecture skeleton helps more than raw code volume.

## When to use
- Starting a small game from scratch
- Scaffolding a genre's core structure
- Organizing a specific game type

## Supported blueprint styles
- 2D platformer
- Top-down shooter
- Endless runner
- Puzzle / interaction game
- Tower defense
- Clicker / incremental
- Card / turn-based prototype

## Output format
- Core loop
- Recommended scenes
- Recommended modules
- Initial script list
- Data/config assets
- UI responsibilities
- What to deliberately keep simple

## Pitfalls
- Provide the smallest viable blueprint, not a giant reusable framework.
- Prefer a short script inventory over "future-proof" template sprawl.

### ui_create_panel
Create a Panel UI element.

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `name` | string | No | "Panel" | Name of the new element |
| `parent` | string | No | null | Parent GameObject name |
| `r` | float | No | 1 | r/g/b/a: colour channels as 0-1 floats (not 0-255). |
| `g` | float | No | 1 | G |
| `b` | float | No | 1 | B |
| `a` | float | No | 0.5 | A |
| `parentEntityId` | string | No | null | Parent entity ID; outranks `parent` |

### ui_create_dropdown
Create a Dropdown UI element with options.

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `name` | string | No | "Dropdown" | Name of the new element |
| `parent` | string | No | null | Parent GameObject name |
| `options` | string | No | null | Options |
| `width` | float | No | 160 | Width |
| `height` | float | No | 30 | Height |
| `parentEntityId` | string | No | null | Parent entity ID; outranks `parent` |

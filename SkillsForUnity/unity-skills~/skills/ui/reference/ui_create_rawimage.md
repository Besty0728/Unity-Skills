### ui_create_rawimage
Create a RawImage UI element (for Texture2D/RenderTexture).

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `name` | string | No | "RawImage" | Name of the new element |
| `parent` | string | No | null | Parent GameObject name |
| `texturePath` | string | No | null | Texture asset path |
| `width` | float | No | 100 | Width |
| `height` | float | No | 100 | Height |
| `parentEntityId` | string | No | null | Parent entity ID; outranks `parent` |

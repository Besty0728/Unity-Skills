### ui_create_slider
Create a Slider UI element.

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `name` | string | No | "Slider" | Name of the new element |
| `parent` | string | No | null | Parent GameObject name |
| `minValue` | float | No | 0 | Min value |
| `maxValue` | float | No | 1 | Max value |
| `value` | float | No | 0.5 | Value |
| `width` | float | No | 160 | Width |
| `height` | float | No | 20 | Height |
| `parentEntityId` | string | No | null | Parent entity ID; outranks `parent` |

### ui_create_canvas
Create a new Canvas.

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `name` | string | No | "Canvas" | Name of the new element |
| `renderMode` | string | No | "ScreenSpaceOverlay" | ScreenSpaceOverlay, ScreenSpaceCamera or WorldSpace (Unity's RenderMode enum names, case-insensitive). |

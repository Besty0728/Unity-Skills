### ui_create_inputfield
Create an InputField UI element.

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `name` | string | No | "InputField" | Name of the new element |
| `parent` | string | No | null | Parent GameObject name |
| `placeholder` | string | No | "Enter text..." | Placeholder |
| `width` | float | No | 200 | Width |
| `height` | float | No | 30 | Height |
| `parentEntityId` | string | No | null | Parent entity ID; outranks `parent` |

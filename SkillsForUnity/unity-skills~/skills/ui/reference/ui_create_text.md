### ui_create_text
Create a Text UI element.

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `name` | string | No | "Text" | Name of the new element |
| `parent` | string | No | null | Parent GameObject name |
| `text` | string | No | "New Text" | Text content |
| `fontSize` | int | No | 14 | Font size |
| `r` | float | No | 0 | r/g/b: colour channels as 0-1 floats (not 0-255). |
| `g` | float | No | 0 | G |
| `b` | float | No | 0 | B |
| `parentEntityId` | string | No | null | Parent entity ID; outranks `parent` |

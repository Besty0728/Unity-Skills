### ui_create_image
Create an Image UI element.

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `name` | string | No | "Image" | Name of the new element |
| `parent` | string | No | null | Parent GameObject name |
| `spritePath` | string | No | null | Sprite asset path |
| `width` | float | No | 100 | Width |
| `height` | float | No | 100 | Height |
| `parentEntityId` | string | No | null | Parent entity ID; outranks `parent` |

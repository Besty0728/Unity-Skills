### ui_find_all
Find all UI elements in the scene.

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `uiType` | string | No | null | Canvas, Button, Slider, Toggle, InputField, Text, Image, RawImage, RectTransform or Unknown (case-insensitive); omit for all types. |
| `limit` | int | No | 50 | Max results |

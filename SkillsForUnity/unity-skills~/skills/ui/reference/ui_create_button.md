### ui_create_button
Create a Button UI element.

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `name` | string | No | "Button" | Name of the new element |
| `parent` | string | No | null | Parent GameObject name |
| `text` | string | No | "Button" | Text content |
| `width` | float | No | 160 | Width |
| `height` | float | No | 30 | Height |
| `parentEntityId` | string | No | null | Parent entity ID; outranks `parent` |

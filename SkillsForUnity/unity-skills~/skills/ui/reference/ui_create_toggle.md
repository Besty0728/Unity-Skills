### ui_create_toggle
Create a Toggle UI element.

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `name` | string | No | "Toggle" | Name of the new element |
| `parent` | string | No | null | Parent GameObject name |
| `label` | string | No | "Toggle" | Label |
| `isOn` | bool | No | false | Is on |
| `parentEntityId` | string | No | null | Parent entity ID; outranks `parent` |

# YooAsset 3.x - Delta Cheat Sheet

The other files in this module are anchored to **v2.3.18**. When the project runs **YooAsset 3.0.4 or later**, read this file first and translate every 2.x name below before writing code. Anchors are the **3.0.7** source (`Runtime/`, `Editor/` of the UPM package); 3.0.4 to 3.0.7 only add members on top of the surface listed here.

- **Check the line first**: `yooasset_check_installed` returns `apiLine` (`"2.x"` / `"3.x"`). Do not infer the line from memory.
- **Supported 3.x range**: `[3.0.4,3.1.0-0)`: one minor line, like 2.x's `[2.3.15,2.4.0-0)`; the `-0` keeps the next minor's prereleases out. 3.0.0-beta to 3.0.3-beta are prereleases and not supported by UnitySkills.
- **Do not rely on `YOOASSET_LEGACY_API`**: it is a user-defined scripting symbol that re-adds some 2.x runtime names as `[Obsolete]` (`Runtime/Compatibility/*`). The Editor side (builder, collector, report) has no such layer. Emit 3.x names.
- **No upstream migration guide**: every row below comes from a 2.3.19 vs 3.0.7 source diff.

## 1. Runtime: bootstrap and initialization

| 2.x | 3.x | Note |
|---|---|---|
| `YooAssets.Initialized` | `YooAssets.IsInitialized` | `YooAsset/YooAssets.cs` |
| `YooAssets.Initialize(ILogger logger = null)` | `Initialize()` / `Initialize(ILogger)` | Calling it twice now **throws** `InvalidOperationException` |
| `YooAssets.SetDefaultPackage(...)` + default-package shortcuts (`YooAssets.LoadAssetAsync`, ...) | **removed** (`YooAssetsExtension.cs` is gone) | Always keep a `ResourcePackage` reference and call it directly |
| `CreatePackage` / `GetPackage` / `ContainsPackage` before `Initialize` | now **throw** | Initialize first |
| `YooAssets.RemovePackage(ResourcePackage)` returns `bool` | `RemovePackage(string packageName)`, `void` | **Throws** if the package is not destroyed yet (`InitializeStatus != None`) |
| `package.InitializeAsync(InitializeParameters)` → `InitializationOperation` | `package.InitializePackageAsync(InitializePackageOptions)` → `InitializePackageOperation` | `ResourcePackage.cs:91` |
| `package.DestroyAsync()` → `DestroyOperation` | `package.DestroyPackageAsync()` → `DestroyPackageOperation` | Destroy, wait, then `RemovePackage(name)` |

Play-mode parameter classes became option classes with properties (object initializers still work):

| 2.x | 3.x |
|---|---|
| `EditorSimulateModeParameters { EditorFileSystemParameters }` | `EditorSimulateModeOptions { EditorFileSystemParameters }` |
| `OfflinePlayModeParameters { BuildinFileSystemParameters }` | `OfflinePlayModeOptions { BuiltinFileSystemParameters }` |
| `HostPlayModeParameters { BuildinFileSystemParameters, CacheFileSystemParameters }` | `HostPlayModeOptions { BuiltinFileSystemParameters, CacheFileSystemParameters }` |
| `WebPlayModeParameters { WebServerFileSystemParameters, WebRemoteFileSystemParameters }` | `WebPlayModeOptions { WebServerFileSystemParameters, WebNetworkFileSystemParameters }` |
| `CustomPlayModeParameters` | `CustomPlayModeOptions { FileSystemParameterList }` |

Shared option properties live on `InitializePackageOptions`: `AutoUnloadBundleWhenUnused`, `BundleLoadingMaxConcurrency`, `WebGLForceSyncLoadAsset`.

File-system factories (`FileSystem/FileSystemParameters.cs`):

| 2.x | 3.x |
|---|---|
| `CreateDefaultEditorFileSystemParameters(packageRoot)` | same name and signature |
| `CreateDefaultBuildinFileSystemParameters(...)` | `CreateDefaultBuiltinFileSystemParameters(...)` |
| `CreateDefaultCacheFileSystemParameters(IRemoteServices, ...)` | `CreateDefaultSandboxFileSystemParameters(IRemoteService, ...)` |
| `CreateDefaultWebRemoteFileSystemParameters(...)` | `CreateDefaultWebNetworkFileSystemParameters(IRemoteService, ...)` |
| `IRemoteServices.GetRemoteMainURL / GetRemoteFallbackURL` | `IRemoteService.GetRemoteUrls(fileName)` → `IReadOnlyList<string>` |

## 2. Runtime: update flow, loading, handles

| 2.x | 3.x | Note |
|---|---|---|
| `EOperationStatus.Succeed` | `EOperationStatus.Succeeded` | Every status check changes |
| `RequestPackageVersionAsync(bool appendTimeTicks = true, int timeout = 60)` | `RequestPackageVersionAsync()` or `(new RequestPackageVersionOptions(appendTimeTicks, timeout))` | Parameterless overload keeps the 60 s default |
| `UpdatePackageManifestAsync(version, timeout = 60)` → `UpdatePackageManifestOperation` | `LoadPackageManifestAsync(new LoadPackageManifestOptions(version, timeout))` → `LoadPackageManifestOperation` | Timeout is **mandatory** |
| `PreDownloadContentAsync(version, timeout)` | `PrefetchManifestAsync(new PrefetchManifestOptions(version, timeout))` | |
| `ClearCacheFilesAsync(EFileClearMode, param)` | `ClearCacheAsync(new ClearCacheOptions(clearMethod[, clearParam]))` | |
| `UnloadUnusedAssetsAsync(int loopCount = 10)` | `UnloadUnusedAssetsAsync()` / `(new UnloadUnusedAssetsOptions(maxLoopCount))` | |
| `CreateResourceDownloader(int max, int retry)` (+ tag overloads) | `CreateResourceDownloader(new ResourceDownloaderOptions(max, retry))` (+ `tag` / `tags` ctors) | Per-asset downloads use `BundleDownloaderOptions` |
| `downloader.BeginDownload()` | `downloader.StartDownload()` | `TotalDownloadCount / TotalDownloadBytes / IsDone / Status / Error` unchanged |
| `DownloadFinishCallback / DownloadUpdateCallback / DownloadErrorCallback` properties | events `DownloadCompleted / DownloadProgressChanged / DownloadError / DownloadFileStarted` | Subscribe with `+=` |
| `package.CheckLocationValid(location)` | `package.IsLocationValid(location)` | |
| `AssetInfo.IsInvalid` | `AssetInfo.IsValid` | **Inverted**: `!a.IsInvalid` becomes `a.IsValid`, never `!a.IsValid` |
| `HandleBase.LastError` | `HandleBase.Error` | |
| `LoadRawFileSync/Async` → `RawFileHandle` | `LoadBundleFileSync/Async` → `BundleFileHandle` | 3.0.1-beta; `EnsureBundleFileAsync` added |

Unchanged: `LoadAsset*`, `LoadSubAssets*`, `LoadAllAssets*`, `LoadScene*`, `AssetHandle.AssetObject / Release() / IsDone / Status`, `PackageValid`, `GetAllAssetInfos()`, `InitializeStatus`, `EPlayMode`.

## 3. Editor: builder

| 2.x | 3.x |
|---|---|
| `AssetBundleBuilderHelper` | `BundleBuilderHelper` (`GetDefaultBuildOutputRoot` / `GetStreamingAssetsRoot` unchanged) |
| `AssetBundleBuilderSetting` | `BundleBuilderSetting` |
| `*BuildinFileCopyOption / *BuildinFileCopyParams` | `*BundledCopyOption / *BundledCopyParams` |
| `*EncyptionServicesClassName` | `*BundleEncryptorClassName` |
| `*ManifestProcessServicesClassName` / `*ManifestRestoreServicesClassName` | `*ManifestEncryptorClassName` / `*ManifestDecryptorClassName` |
| `EBuildinFileCopyOption` | `EBundledCopyOption` (same members) |
| `BuildParameters.BuildinFileRoot` | `BundledFileRoot` (fields became auto-properties) |
| `IEncryptionServices / IManifestProcessServices / IManifestRestoreServices` | `IBundleEncryptor / IManifestEncryptor / IManifestDecryptor` |
| `EBuildBundleType { VirtualBundle=1, AssetBundle=2, RawBundle=3 }` | `EBundleType { AssetBundle=2, RawBundle=3, ArchiveBundle=4, VirtualAssetBundle=12, ... }` |
| `EBuildPipeline.BuiltinBuildPipeline` | `LegacyBuildPipeline`; new `ArchiveFileBuildPipeline`, `InstantAssetBuildPipeline` (Tuanjie only) |
| `PackageInvokeBuildParam` + `AssetBundleSimulateBuilder.SimulateBuild` | `PackageBuildParameters { BuildPipelineName, BuildBundleType }` + `BundleSimulateBuilder.SimulateBuild` |
| `EditorSimulateModeHelper.SimulateBuild(name)` | `EditorSimulateBuildInvoker.Build(name, (int)EBundleType.VirtualAssetBundle)` |

Traps:
- `PackageBuildParameters.BuildBundleType` defaults to `0` (`EBundleType.None`), which `BuildParameters.CheckBuildParameters` rejects. Always set `VirtualAssetBundle` for a simulate build.
- Builder EditorPrefs keys moved from an `Application.productName` prefix to `PlayerSettings.productGUID`, so settings saved by the 2.x Builder window read back as defaults on 3.x.
- `BuildParameters.EnableAssetPathValidation` (3.0.6) stops a build on Unicode format-control characters in asset paths. An empty `ScriptableBuildParameters.BuiltinShadersBundleName` now logs a build warning.
- Menus `YooAsset/AssetBundle Builder|Collector|Reporter|Debugger` became `YooAsset/Bundle Builder|Collector|Reporter|Debugger`; the `yooasset_open_*_window` skills pick the path per line and echo it as `menuPath`.

## 4. Editor: collector, rules, report

| 2.x | 3.x |
|---|---|
| `AssetBundleCollectorSettingData / Setting / Package / Group`, `AssetBundleCollector` | `BundleCollectorSettingData / BundleCollectorSetting / BundleCollectorPackage / BundleCollectorGroup`, `BundleCollector` |
| `GetActiveRuleNames / GetPackRuleNames / GetFilterRuleNames / GetIgnoreRuleNames` | `GetGroupActiveRuleNames / GetBundlePackRuleNames / GetAssetFilterRuleNames / GetAssetIgnoreRuleNames` |
| `HasActiveRuleName / HasPackRuleName / HasFilterRuleName / HasIgnoreRuleName` | `HasGroupActiveRuleName / HasBundlePackRuleName / HasAssetFilterRuleName / HasAssetIgnoreRuleName` |
| `IActiveRule / IPackRule / IFilterRule / IIgnoreRule`, `FilterRuleData` | `IGroupActiveRule / IBundlePackRule / IAssetFilterRule / IAssetIgnoreRule`, `AssetFilterRuleData` (readonly struct) |
| asset `Assets/AssetBundleCollectorSetting.asset` | `Assets/BundleCollectorSetting.asset` (same script GUID) |
| `BuildReport.IndependAssets`, `ReportIndependAsset` | `IndependentAssets`, `ReportIndependentAsset` |
| `ReportBundleInfo.FileCRC` | `FileCrc` |
| `ReportAssetInfo.AssetGUID`, `ReportIndependAsset.AssetGUID` | `AssetGuid` |
| `YooAsset.Editor.AssetInfo` | `EditorAssetInfo` (no more clash with the runtime `AssetInfo`) |

Unchanged: collector data fields, `Create/Modify/Remove*`, `SaveFile / FixFile / IsDirty`, default rule class names (`EnableGroup`, `AddressByFileName`, `PackDirectory`, `CollectAll`, `NormalIgnoreRule`), `ECollectorType`, `GetAddressRuleNames / HasAddressRuleName`. New: `BundleCollectorSettingData.HasSettingAsset()` probes without creating the asset.

Reports are `JsonUtility` field dumps. A `.report` written by one major version and read by the other loses the renamed fields silently (empty lists, zero CRC, empty GUID). Read a report with the major version that wrote it; the UnitySkills report skills add a `warnings` entry when `Summary.YooVersion` differs from the installed line.

## 5. Removed with no replacement

- **AssetArt Scanner and AssetArt Reporter** (`AssetArtScannerSettingData`, `AssetArtScannerConfig`, `ScannerResult`, menus `YooAsset/AssetArt Scanner|Reporter`). The six `yooasset_*assetart*` skills return `SKILL_ERROR` "YooAsset 3.x removed this feature" on 3.x. An existing `AssetArtScannerSetting.asset` becomes a missing-script asset.
- Default-package shortcuts on `YooAssets` (see section 1).

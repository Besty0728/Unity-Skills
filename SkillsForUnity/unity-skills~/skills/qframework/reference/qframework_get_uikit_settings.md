### qframework_get_uikit_settings
Read the UIKit project settings in `Assets/QFrameworkData/ProjectConfig/ProjectConfig.json`: default namespace, UI script and prefab output directories, and the assembly names `UICodeGenerator` searches for bind types.

**Parameters:** None

**Returns:** `namespaceName`, `uiScriptDir`, `uiPrefabDir`, `assemblyNamesToSearch`, `isDefaultNamespace`
